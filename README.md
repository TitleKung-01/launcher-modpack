# ✨ Modern Creative Portfolio | Vue 3 + TypeScript

A sophisticated, high-performance portfolio template designed for senior developers and creative professionals. Built with a focus on **UX/UI excellence**, featuring a premium **glassmorphism** aesthetic and seamless interactions.

## 🌟 Key Highlights

- 💎 **Premium Glassmorphism UI:** Modern, clean, and professional dark-themed design.
- 🌍 **Internationalization (i18n):** Full support for English, Thai, Japanese, and Polish.
- 🎬 **Fluid Animations:** Powered by `motion-v` (Motion One) for high-frame-rate interactions.
- 📱 **Fully Responsive:** Optimized for all devices from mobile to ultra-wide displays.
- ⚡ **Performance First:** Built with Vite for near-instant HMR and optimized production builds.

## 🛠️ Tech Stack

- **Core:** [Vue 3](https://vuejs.org/) (Composition API)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation:** [Motion-V](https://motion.dev/vue/quick-start)
- **Localization:** [vue-i18n](https://vue-i18n.intlify.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)

## 🚀 Getting Started

1. **Clone & Install:**
   ```bash
   git clone <your-repo-url>
   cd portfolio-customer
   npm install
   ```

2. **Development:**
   ```bash
   npm run dev
   ```

3. **Production Build:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components/portfolio/` - Core UI sections (Hero, Works, Testimonials, Contact).
- `src/data/portfolio.ts` - **Single Source of Truth** for profile data and content.
- `src/i18n/` - Localization configurations and translation files.
- `src/types/` - Centralized TypeScript interfaces.

## 📝 Customization

This project is designed to be easily customizable. Simply update `src/data/portfolio.ts` with your own profile, work history, and testimonials to make it yours.
